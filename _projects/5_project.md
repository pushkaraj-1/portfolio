An open-source integration connecting LLM AI agents to the **Godot 4 Game Engine** via Anthropic's Model Context Protocol (MCP).

- Enables AI assistants to inspect node hierarchies, inspect scene files, execute GDScript routines, and modify project properties directly from IDEs.
