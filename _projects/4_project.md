Cold Reach is an automated cold outreach personalization platform that analyzes recipient company data, GitHub activities, and public research to craft highly relevant, contextual emails.

- **Stack**: Next.js 16, TypeScript, Tailwind CSS, LLM API integration.
- **Features**: Real-time prompt streaming, recipient research aggregation, deliverability verification.
